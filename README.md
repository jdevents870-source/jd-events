# JD Events — دليل التشغيل ولوحة التحكم

موقع **JD Events** (فنادق وقاعات ومناسبات) مع **لوحة تحكم كاملة** وخادم محلي بلغة C#
يحفظ كل التعديلات على القرص، بحيث يراها كل الزوّار مباشرةً.

---

## ١. المتطلبات

- نظام **Windows**.
- **.NET Framework 4.8** (مُضمَّن في ويندوز 10/11 — يوفّر `csc.exe`).
- متصفّح حديث (Chrome / Edge / Firefox).

> لا يلزم Node.js أو Python أو أي مكتبات خارجية. الخادم مستقل تماماً.

---

## ٢. التشغيل السريع

1. شغّل الخادم:
   ```
   server\start-server.bat
   ```
   هذا الملف يبني الخادم تلقائياً (إن لزم) ثم يشغّله على المنفذ **8787**.

2. افتح الموقع من المتصفّح:
   ```
   http://localhost:8787/
   ```

> **مهم جداً:** يجب فتح الموقع عبر `http://localhost:8787/` وليس عبر `file://`.
> الصفحات تحتاج الخادم لقراءة/حفظ البيانات؛ عند الفتح المباشر للملفات لن يعمل الحفظ.

لإيقاف الخادم: أغلق نافذة الطرفية، أو أنشئ المهمة في مدير المهام وأوقف `JDEventsServer.exe`.

### إعادة البناء يدوياً (اختياري)
```
server\build.bat
```

---

## ٣. الدخول إلى لوحة التحكم

- صفحة الدخول: `http://localhost:8787/pages/login.html`
- لوحة التحكم: `http://localhost:8787/pages/admin/`

**بيانات الدخول الافتراضية** (من `server/config.json`):

| البريد الإلكتروني | كلمة المرور |
|---|---|
| `admin@jdevents.jo` | `jdevents2026` |

يُنصح بتغيير كلمة المرور فوراً من صفحة **الإعدادات**:
`pages/admin/settings.html` ← «تغيير كلمة المرور».

---

## ٤. إدارة المحتوى

كل الصفحات تتطلب تسجيل دخول المدير، وكل تعديل يُحفظ على القرص فوراً.

| الصفحة | الرابط | الوظيفة |
|---|---|---|
| الفنادق | `pages/admin/hotels-list.html` | عرض/بحث/حذف الفنادق |
| إضافة/تعديل فندق | `pages/admin/hotel-edit.html` | الاسم، المدينة، النجوم، الوصف، المرافق، الإحداثيات |
| قاعات الفندق | `pages/admin/rooms-list.html?hotel_id=<معرّف الفندق>` | عرض/حذف قاعات الفندق |
| إضافة/تعديل قاعة | `pages/admin/room-edit.html?hotel_id=<معرّف الفندق>` | الأبعاد والمساحة والصور والمخطط |
| النموذج ثلاثي الأبعاد | `pages/admin/room-3d-edit.html?room_id=<معرّف القاعة>` | تصميم وحفظ النموذج 3D |
| الإعدادات | `pages/admin/settings.html` | بيانات الحساب، الإحصاءات، تغيير كلمة المرور |

### إمكانات القاعة
- **صور متعددة**: رفع عدة صور، اختيار الصورة الرئيسية (الغلاف)، إعادة الترتيب، الحذف.
- **مخطط القاعة**: صورة أو ملف **PDF**.
- **الأبعاد**: الطول × العرض × الارتفاع (بالمتر)، والمساحة تُحسب تلقائياً.
- **التفاصيل الإنشائية**: الأعمدة (مع إحداثيات)، الأبواب، النوافذ.
- **السعات**: سعات متعدّدة حسب نوع التخطيط (مسرحي، فصلي...).

### النموذج ثلاثي الأبعاد (لكل قاعة على حِدة)
- يُبنى المشهد تلقائياً من **أبعاد القاعة الحقيقية**.
- زر **«حفظ كمسودة»**: يحفظ التصميم دون إتاحته للزوّار.
- زر **«حفظ ونشر للزوار»**: يجعل النموذج ظاهراً في صفحة القاعة العامة.
- يُحفظ تصميم مستقل لكل قاعة، ويمكن حذف النموذج من نفس الصفحة.

---

## ٥. ظهور التعديلات للزوّار

- ملف الموقع العام `data/venues.js` يُعاد توليده **تلقائياً** عند كل عملية حفظ.
- الصفحات العامة (`venues.html`، `hotel-detail.html`، `room-detail.html` …) تقرأ منه مباشرةً.
- يمكن فرض إعادة التوليد يدوياً من **الإعدادات** ← «إعادة توليد بيانات الموقع العام».

## ٦. مكان تخزين البيانات

| المسار | المحتوى |
|---|---|
| `data/db/hotels.json` | الفنادق |
| `data/db/rooms.json` | القاعات |
| `data/db/models.json` | نماذج 3D |
| `data/db/admin_users.json` | حسابات المديرين (كلمة المرور مُشفّرة بملح) |
| `uploads/` | الصور والمخططات المرفوعة |
| `data/venues.js` | ملف عام مُولَّد آلياً (لا تُحرّره يدوياً) |

**نسخ احتياطي:** انسخ مجلدَي `data` و `uploads`.

## ٧. الإعدادات — `server/config.json`

```json
{
  "port": 8787,
  "tokenSecret": "…",
  "admin": { "email": "admin@jdevents.jo", "password": "jdevents2026", "name": "مدير JD Events" },
  "maxImageSizeMB": 5,
  "maxPlanSizeMB": 15,
  "tokenTtlHours": 12
}
```

- `port`: منفذ الخادم.
- `tokenSecret`: السر المستخدم لتوقيع رموز الدخول — **غيّره**.
- `admin`: حساب المدير الأول (يُنشأ عند أول تشغيل فقط؛ بعدها تُدار كلمة المرور من اللوحة).
- `maxImageSizeMB` / `maxPlanSizeMB`: حدود حجم الرفع.
- `tokenTtlHours`: مدة صلاحية الرمز.

بعد تعديل `config.json` أعد تشغيل الخادم.

---

## ٨. ملاحظات أمان

- لا توجد كلمات مرور أو مفاتيح في واجهة الموقع؛ الدخول يتم عبر رمز موقّع (HMAC-SHA256)
  يُخزَّن في `localStorage` تحت المفتاح `jd_token`.
- جميع عمليات الإنشاء/التعديل/الحذف والرفع تتطلّب مصادقة على الخادم (تُرفض بدون رمز صالح).
- قبل أي نشر عام: غيّر كلمة مرور المدير و`tokenSecret`، ولا تُشارك مجلد `server/`.

---

## ٩. الانتقال لاحقاً إلى قاعدة بيانات مستضافة

طبقة التخزين معزولة في الخادم (`LoadAll` / `SaveList` والملفات `data/db/*.json`).
لاستبدالها بقاعدة بيانات حقيقية (SQL Server / PostgreSQL / MySQL):

1. استبدل قراءة/كتابة الملفات بنداءات قاعدة البيانات داخل `server/JDEventsServer.cs`.
2. أبقِ مسارات الـ API كما هي — الواجهة لا تحتاج أي تغيير.
3. انقل الملفات المرفوعة إلى تخزين سحابي (S3 مثلاً) عند الحاجة.

## ١٠. استكشاف الأخطاء

| المشكلة | الحل |
|---|---|
| «تعذّر الاتصال بالخادم» | تأكد أن الخادم يعمل، وافتح الموقع عبر `http://localhost:8787/` |
| المنفذ 8787 مشغول | غيّر `port` في `server/config.json` ثم أعد التشغيل |
| الصفحات تعيد التوجيه لصفحة الدخول | سجّل الدخول من `pages/login.html` |
| لم يظهر التعديل للزوار | اضغط «إعادة توليد بيانات الموقع العام» في الإعدادات، ثم حدّث الصفحة |
| فشل البناء | تأكد من وجود `csc.exe` (‎.NET Framework 4.8) على ويندوز |
