JD Events — نسخة جاهزة للموقع

ابدأ من index.html، وصفحة المصمم ثلاثي الأبعاد موجودة في:
pages/room-designer.html

التعديلات:
- استبدال لوحة التخطيط ثنائية الأبعاد بمشهد قاعة ثلاثي الأبعاد تفاعلي.
- اختيار حجم القاعة: صغيرة، متوسطة، أو كبيرة.
- قوالب توزيع: مسرح، تدريب، طاولات دائرية، وشكل U، مع خيار تجهيز تلقائي أو البدء بقاعة فارغة.
- إضافة المقاعد والطاولات والمنصة والشاشة، ثم سحب العناصر وتحريكها أو تدويرها أو نسخها أو حذفها.
- حفظ التصميم على الجهاز وتنزيله كملف JSON، مع إمكانية فتح ملف محفوظ.
- الأسعار غير محددة؛ لا توجد أسعار افتراضية في المصمم.

المشهد مبني كقاعة عامة قابلة لتغيير الحجم، وليس نسخة هندسية مطابقة لفندق محدد. يحتاج المصمم إلى اتصال بالإنترنت لتحميل مكتبة Three.js والخط العربي.
